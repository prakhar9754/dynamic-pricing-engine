# 🛒 Dynamic Pricing Engine

## 📌 Overview
This project builds a machine learning-based dynamic pricing system using ecommerce behavior data.

## 🎯 Objectives
- Analyze customer behavior
- Predict product demand
- Recommend optimal pricing

## 🤖 Approach
- Classification → Demand Prediction
- Regression → Price Optimization

## 📊 Dataset
Ecommerce Behavior Dataset (sampled)

## 🚀 Project Structure
- Problem Framing
- Data Cleaning
- Feature Engineering
- Modeling

## 🛠 Tech Stack
- Python
- Pandas
- Scikit-learn
- joblib
- fast api
